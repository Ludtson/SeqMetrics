SeqMetrics · architecture

One orchestrator, eight independent modules

Every module reads a plain CDS or protein FASTA and writes one TSV. run_features.py only checks the dependencies a requested module actually needs, resolving each one through whichever of a direct PATH binary, native conda, WSL-bridged conda, or an isolated venv it was actually set up in — nobody installs the whole panel to run one module.
